# 环节一：模板截取（起止定位 + 原样切片）实现逻辑与接口

## 设计原则

**不提取骨架、不重排版**：确定模板起始/终止标题后，把中间部分原样切成新 docx。实现 = 复制源 Document 对象 → 删除起止范围之外的正文块 → 保存。因此 template.docx 100% 继承源文件的样式表、标题编号、表格边框、占位符空格、页眉页脚——这是"局部修改、禁止改写"的最强保障。

## 起止定位算法

1. 遍历 body 子元素（段落+表格保持文档序），记录段落文本索引。
2. **起始**：`--start` 关键词命中即止；缺省正则 `(响应|投标|应答)\s*文件\s*(的)?格式|文件格式及附件|响应文件组成` 且该段须为标题（样式 Heading/标题N，或文本族判定：第X章 / 一、 / 1.1）。
3. **终止**：`--end` 关键词命中段（不含）；缺省 = 起始之后第一个**同族且同级/更高级**标题（如起始是"第X章"→下一个"第X章"；起始是"三、"→下一个"三、"或"第X章"），无则至文末。
4. **定位失败**（起始找不到 / `--end` 找不到 / `--require` 有 miss）→ 退出码 3 + stderr MISS 清单 → **停下向用户确认**，不得猜测章节。

## template.json（元数据契约）

```jsonc
{
 "source": "询比采购文件….docx", "template": "template.docx",
 "extracted_at": "…",
 "start": {"child_index": 512, "title": "三、响应文件格式及附件", "approx_page": 24},
 "end":   {"child_index": 890, "title": "四、价格调整", "approx_page": 41},
 "approx_pages": 18,
 "headings": ["1.1 投标函及投标函附录", "1.2 法定代表人身份证明", …],  // 章内全部标题
 "paragraphs": 402, "tables": 22, "removed_blocks": 356,
 "misses": [{"requirement": "偏离表", "hit": false}]
}
```

- `headings` 是环节四 verify C 轨道的"模板节完整性"基准（成稿正文必须逐条含这些标题，删模板节即 FAIL）。
- 近似页码按 780 字/页估算，仅用于向用户报"模板在第 N 页到第 M 页"辅助确认，精确页码以 Word 打开为准。

## CLI 与退出码

```
python extract_template.py <tender.docx> -o template.docx [-m template.json]
    [--start K] [--end K] [--require A,B]
```

| 码 | 含义 | 动作 |
|---|---|---|
| 0 | 切片成功、require 全命中 | 进环节二 |
| 2 | 文件不可读/无段落 | 报告用户 |
| 3 | 起止无法定位 或 必备模板 miss | **W1：向用户确认起止页码/替代方案** |

## 复核关口（agent 必做）

切片后向用户复述："模板起始《X》、终止《Y》之前，约 N–M 页，含格式件：投标函/报价表/…，是否正确？"——用户确认后才进入填空。终止自动判定时尤其必要（部分文件模板章后还有"格式附件"混排）。
